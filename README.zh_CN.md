# 诅咒契约 · Accursed Covenant

**简体中文** · [English](README.md)

**《诅咒契约》**是一款可直接在浏览器运行的单人暗黑动作 RPG 原型，融合肉鸽闯关、类吸血鬼幸存者战斗、随机地牢、增量成长和暗黑式刷宝。项目可部署到任意静态网站，不需要游戏服务器、数据库或额外的游戏引擎运行时。

> 当前版本：**0.15.1** · 可游玩的桌面端 Demo · TypeScript + Phaser 3 + Vite

## 游戏特色

- **三名可选角色：**雷霆术士、亡灵召唤师和血刃骑士拥有独立外貌、技能池、绝技和天赋树；雷霆术士还能积蓄元素共鸣来强化下一次施法。当前浏览器会话内共用装备、背包和金币。
- **武器与进化特性：**八类武器拥有不同射程、攻速、攻击范围、投射物和连击规则；30 条技能进化均有对应的传奇契约。
- **八图连续远征：**每局需要通过八张逐渐增强的随机地图，包含 5–15 个主线房间、回环、走廊、隐藏宝库、可破坏墙、遭遇、宝藏和守卫竞技场；第八图以巨型三阶段最终首领收尾。
- **十五种地图主题：**洞穴、地牢、教堂、废弃村庄、地狱、山脉、城镇、皇宫、墓穴、下水道、冰封遗迹、沼泽、矿坑、沙漠神殿和深渊堡垒均有独立结构、机关、遭遇、怪物生态和遗物。
- **自动与手动施法：**四个常规技能可自动循环，也可关闭自动施法后用数字键 1–4 手动释放。技能栏实时显示各自冷却；鼠标决定施法方向，超过射程时会落在该方向的最远有效位置。右键基础攻击不消耗法力。
- **三十种技能进化：**十五个常规技能均可在三级选择两条互斥进化路线，并在六级获得对应分支的终极机制。
- **完整刷宝系统：**七档品质、装备等级、六阶词缀、前后缀、八种会改变攻击方式的武器、八个装备槽、套装、暗金、传奇、暗黑风格鼠标悬停详情与属性比较、按品质变色的动态掉落光柱、地面名称和拾取筛选。
- **清晰的装备信息：**装备悬停面板会显示完整词缀、替换比较、武器机制，以及该物品与当前技能和天赋的关系。
- **怪物生态：**60 套动画怪物按照主题和阶级组成近战前排、远程压制、伏击、坦克和支援队伍，并拥有治疗、护盾、复活、传送、包围和异常状态能力。
- **长期成长：**每名角色拥有独立的 18 节点天赋树，分为三条六节点分支，每节点三级；退点返还已投入金币的一半。
- **营地经济与随机事件：**动态等级商人、铁匠、装备升级、乞丐与旅客投资、诅咒宝箱、血誓祭坛、猎杀契约，以及隐藏的怪物陈列回廊。
- **完整美术表现：**固定 2.5D 等距镜头、角色八方向动作、基于墙脚位置的动态遮挡、主题地板、战争迷雾、屏外威胁标记、分类战斗数字、动态传送门、分层特效、动画经验球，以及暗黑风格红色生命球和蓝色法力球。
- **中英双语：**标题页、HUD、菜单、装备说明、事件、地图名称和战斗信息均可即时切换。

## 本地运行

需要 Node.js 22.12 或更新的兼容版本，以及 npm。项目已使用 Node.js 22.17.0 验证。

```bash
git clone https://github.com/BlcaCola/Accursed-Covenant.git
cd Accursed-Covenant
git lfs pull
npm ci
npm run dev
```

打开 Vite 在终端显示的地址，默认是 `http://127.0.0.1:5173/`。安装依赖后，Windows 也可以运行 `启动Demo.cmd`。

仓库使用 [Git LFS](https://git-lfs.com/) 保存大量逐帧 PNG。请在克隆前安装 Git LFS，或者在克隆后执行 `git lfs install` 和 `git lfs pull`。

## 操作方式

| 输入 | 功能 |
| --- | --- |
| 鼠标左键 | 点击地面自动寻路移动（默认启用） |
| WASD / 方向键 | 按屏幕方向移动，并中断当前点击移动路线 |
| 鼠标右键 | 朝指针方向进行不消耗法力的基础攻击 |
| 鼠标指向 | 确定技能方向；超出射程时落在同方向的最远有效位置 |
| 1–4 | 关闭自动施法后，手动释放对应常规技能 |
| Space | 幽影闪避；两次充能，不消耗法力 |
| Q | 当前角色绝技；消耗 40 法力，冷却 8 秒 |
| R | 使用血瓶，恢复 50% 最大生命 |
| E | 与宝箱、NPC、传送门和贪欲祭坛互动 |
| F | 拾取 190 范围内最近且符合筛选条件的装备 |
| I | 打开装备与背包；战斗暂停 |
| Esc | 暂停、继续或关闭当前面板 |
| Tab | 展开或收起地图 |
| M | 开关音效 |
| EN / 中 | 即时切换语言 |

自动施法开关位于暂停菜单。地上的尸骸会保留一段时间，亡灵召唤师的尸骸爆破会优先引爆鼠标落点附近的尸骸。

当前 Demo 以桌面键盘和鼠标为目标，尚未实现完整的手柄、触屏和移动端布局。

## 核心系统

### 远征与遭遇

每局从一级构筑开始。地图生成器先保证关键路线连通，再加入回环、可选支路、房间遭遇、场景物件和一个隔离的隐藏宝库。地图越深入，房间与敌群越多。玩家必须净化关键房间，才能解除地图守卫房的封印。

房间遭遇包括围攻、精英、生存、猎杀、机关和宝藏伏击。可选的诅咒宝箱与猎杀契约会持续生成增援，直到成功或失败。奖励房可在匹配等级的装备、金币和恢复之间三选一。

### 难度与贪欲

怪物与装备等级由地图深度和角色等级决定。贪欲共有 15 阶，只提高怪物生命、攻击、防御和密度，同时增加高品质装备概率；不会提高怪物或装备等级。贪欲 10 级之前不会出现史诗及以上品质。

### 装备与经济

装备由底材、等级、品质、随机词缀和机制效果组成。武器种类会改变攻击方式，而不只是提供数值。商店商品维持在当前进度附近，铁匠可以让装备匹配当前等级或提升品质。

金币用于交易、锻造和三名角色各自的天赋树。单个角色升满需要 31,860 金币，目标节奏约为八至十局普通远征。

### 仅限当前会话的进度

游戏只在内存中保留进度。同一页面内重复远征会继承装备、背包、金币、翅膀和三棵天赋树；刷新或关闭页面后全部清空。当前项目不使用 `localStorage`、`sessionStorage`、IndexedDB、Cookie、Service Worker、账号或云存档。

## 项目结构

```text
src/
├── core/      确定性战斗、地图、掉落、AI 和成长规则
├── render/    Phaser 场景、精灵、特效、地形、镜头和音效
├── ui/        DOM 界面、菜单、HUD、背包和调试工具
├── i18n.ts    中英文运行时文本
└── main.ts    应用入口和会话生命周期
public/
├── assets/    角色、怪物、首领、NPC、翅膀、特效、UI 和环境素材
├── licenses/  第三方授权说明
└── screenshots/
scripts/       素材规范化与清单生成脚本
tests/         Vitest 逻辑/模拟测试与 Playwright 浏览器流程
```

领域层不依赖 Phaser 或 DOM。`Run` 以固定 1/60 秒步长推进战斗，只输出普通状态和一次性视觉事件；渲染层与界面层负责消费数据。影响玩法的随机数使用固定种子，因此地图和掉落可以在测试中复现。

## 素材规范

动画角色使用独立透明 PNG，命名格式为 `{方向}_{动作}_{帧号}.png`。方向按顺时针排列：`0` 上、`1` 右上、`2` 右、`3` 右下、`4` 下、`5` 左下、`6` 左、`7` 左上。动作可使用 `stand`、`run`、`attack`、`skill`、`hit` 和 `death`。

增加或替换素材后，按需重新生成清单：

```bash
python scripts/generate-sprite-manifest.py
python scripts/build_effect_manifest.py
```

角色、环境和特效素材分别存放在英文目录中。地面装备统一使用 `blue-glow` 动画并按品质调整颜色；`frame-effects` 保留给装备本身的展示效果。

## 构建与部署

```bash
npm ci
npm run build
```

将 `dist/` 内全部内容上传到任意静态网站即可。资源使用相对路径，可以部署在域名根目录，也可以放在 `/games/accursed-covenant/` 等子目录。正式游戏不需要 Node.js 服务、API、WebSocket、数据库或外部 CDN。不要通过本地 `file://` 地址启动正式游戏。

### GitHub Pages

仓库已包含 `.github/workflows/deploy-pages.yml`，部署步骤如下：

1. 打开仓库的 **Settings → Pages**。
2. 在 **Build and deployment** 中把 Source 设为 **GitHub Actions**。
3. 推送到 `main`，或者在 Actions 页面手动运行 **Deploy GitHub Pages**。
4. 工作流成功后访问 `https://blcacola.github.io/Accursed-Covenant/`。

工作流会下载 Git LFS 素材、运行测试、构建 `dist` 并部署该目录。Vite 已使用 `base: './'`，无需再手动填写仓库子路径。

当前静态素材约为 760 MB，仍低于 GitHub Pages 发布站点 1 GB 的限制，但剩余空间不多，首次下载也会较重。后续应优先合并重复图集、在合适位置使用 WebP/AVIF，并只加载当前地图主题实际需要的帧。

## 当前限制

- 当前正式支持桌面键盘和鼠标。
- Safari、Firefox、移动端触控、手柄和长时间硬件兼容性仍需单独验证。
- 当前数值适用于持续迭代中的 Demo，后续仍会调整。
- 账号和云存档计划在后续阶段实现。
- 大量逐帧素材使首次完整下载体积较大；运行时会按角色、方向和实际使用的特效分批加载。
